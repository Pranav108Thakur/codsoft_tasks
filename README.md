# CodSoft Artificial Intelligence Internship

This repository contains the projects completed as part of my *Artificial Intelligence Internship at CodSoft*.

## Projects

### 1. AI Chatbot

An interactive *AI Chatbot* application developed using Python and Streamlit. The chatbot provides a conversational interface where users can interact with the AI and receive responses.

*Key Concepts:*
- Artificial Intelligence
- Chatbot Development
- Python
- Streamlit
- Interactive User Interface

### 2. Movie Recommendation System

A *Machine Learning-based Movie Recommendation System* that recommends similar movies based on the movie selected by the user.

*Key Concepts:*
- Recommendation System
- Machine Learning
- Similarity-Based Recommendation
- Data Processing
- API Integration
- Streamlit

### 3. Tic-Tac-Toe AI Game

An interactive *AI-powered Tic-Tac-Toe game* where the user plays against an AI opponent. The AI uses the *Minimax Algorithm* to select its moves and the application tracks the game score.

*Key Concepts:*
- Artificial Intelligence
- Minimax Algorithm
- Game AI
- Game Logic
- Decision Making
- Streamlit
